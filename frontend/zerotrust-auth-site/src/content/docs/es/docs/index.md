ZeroTrust Auth es una plataforma open source de autenticación y autorización basada en
**Zero Trust**: se verifica cada petición, no solo el login.

Esta documentación se está escribiendo. Por ahora esta página es un marcador para que
el link **Docs** de la portada tenga a dónde ir.
